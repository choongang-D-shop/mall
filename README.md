# 쇼핑몰 관리자 페이지 (Servlet/JSP 기반 미니 프로젝트)

# 프로젝트 개요

중앙정보처리학원의 교육 과정 중, Servlet/JSP를 활용하여 웹 개발의 기초를 다지기 위해 진행한 미니 프로젝트입니다. 프레임워크 없이 순수 Java Web 기술만으로 웹 애플리케이션의 기본 동작 원리를 이해하는 것을 목표로 했습니다.

# 프로젝트 기간

- 2025.03.03 ~ 2025.03.13

# 기술 스택

- **Backend:** `Java`, `Servlet`, `JSP`, `JDBC`
- **Database:** `MySQL`
- **IDE:** `STS`
- **Server:** `Apache Tomcat`


# 주요 기능 및 나의 역할

이 프로젝트는 초기 팀 단위로 기획되었으나, 프로젝트 진행 과정에서의 어려움으로 인해 각자 담당한 파트를 중심으로 개발을 진행했습니다. 저는 그중 **쇼핑몰 관리자 환경설정 기능의 백엔드 개발**을 담당했습니다.

제가 구현한 주요 기능은 다음과 같습니다.

1.  **DB 테이블 설계:** 쇼핑몰의 각종 설정 값을 저장하기 위한 `site_config` 테이블을 직접 설계했습니다.
2.  **데이터베이스 연동:** 순수 `JDBC API`를 사용하여 데이터베이스 커넥션을 관리하고, 데이터 영속성을 처리했습니다.
3.  **데이터 저장 로직 구현:**
    - 관리자 페이지(HTML Form)에서 전송된 20개 이상의 설정 값을 `Servlet`으로 받아 처리했습니다.
    - 받은 데이터를 DB 테이블에 `INSERT` 또는 `UPDATE` 하는 백엔드 로직을 구현했습니다.


# 이 프로젝트를 통해 배운 점

이 프로젝트는 팀원들과의 소통 문제 등 여러 어려움이 있었지만, 오히려 저에게는 웹 개발의 가장 근본적인 원리를 깊이 있게 파고들 수 있었던 소중한 경험이었습니다. 
프레임워크의 도움 없이 직접 JDBC 커넥션을 관리하고, SQL 쿼리를 작성하며 데이터의 흐름을 눈으로 좇는 과정은 이후 Spring과 같은 프레임워크가 어떤 문제들을 해결해주고, 왜 필요한지를 몸소 깨닫게 해준 훌륭한 밑거름이 되었습니다. 
비록 완성도 높은 결과물을 만들지는 못했지만, 가장 중요한 기본기를 단련할 수 있었던 의미 있는 프로젝트였습니다.
